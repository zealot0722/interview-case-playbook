# Case Submission Playbook For GPT

Use this as compact GPT knowledge for interview-case preparation.

## Core Method

Do not start with charts. Start with auditability.

1. Inventory the raw files and sheets.
2. Build cleaned/enriched data without overwriting raw inputs.
3. Create row-level issue logs with source file, sheet, row, field, reason, and action.
4. Find the business thesis from the data, then try to disprove it.
5. Build a dashboard that lets reviewers move from KPI to row-level evidence.
6. Write a 1-3 page strategy document with thesis, key numbers, recommendations, limits, and phased roadmap.
7. Package cleanly and verify every artifact agrees.

## What Strong Insight Looks Like

Strong insight is not a long list of charts. It is a corrected causal story:

- What looks like non-compliance may actually be planning over-conservatism.
- A broad candidate set must be tightened into an actionable feasibility gate.
- A real-time optimization proposal should be delayed if the current dataset lacks stop sequence, driver location, road network, and rate-card data.

## AI Usage

Use AI as:

- critique partner,
- implementation accelerator,
- test and packaging assistant,
- adversarial reviewer.

Do not use AI as unchecked source of conclusions.

Best interview phrasing:

```text
I used AI to accelerate implementation and critique the framing, but I re-ran key claims against raw data. That verification changed the thesis and narrowed the recommendation scope. I treated AI output as a draft to validate, not a result to ship.
```
