# AI Usage Disclosure Patterns

Use concise, concrete disclosure. The goal is to show effective AI leverage and human judgment.

## Strong Pattern

```text
AI was used as a critique and implementation accelerator, not as an unchecked source of conclusions. Key claims were re-run against the raw data; that validation changed [initial thesis] into [corrected thesis] and tightened [metric] from [weak rule] into [verified rule].
```

## Workflow Pattern

```text
The human operator defined the analytical frame and final scope. AI was used to generate implementation drafts, challenge assumptions, build tests, and search for inconsistencies. Final numbers and recommendations were verified against raw data before packaging.
```

## Interview Answer Pattern

```text
I used AI in two roles: implementation acceleration and adversarial critique. I did not treat AI output as ground truth. The most important step was re-running key claims against the raw files, which corrected the thesis and narrowed the recommendation scope.
```

## Avoid

- "AI made this dashboard."
- "The model found the insight."
- "I used AI to analyze the data" without saying how it was verified.
- Long prompt logs in the submission.
